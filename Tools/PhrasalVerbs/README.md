# Phrasal verb gallery source

`entries.tsv` is the authored source for all 300 cards. Each row contains an expression, one meaning, an original example, a CEFR band, a two-object scene recipe, and a VoiceOver description. Run `python3 Tools/PhrasalVerbs/build_gallery.py` to regenerate the compiled Swift catalog, JSON validation snapshot, and 300 SVG assets. Run `python3 Tools/validate_svg_assets.py --phrasal` to validate them. The app reads the compiled catalog, so its content does not depend on an Xcode resource bundle copy.

The core 150 expressions in `phave_150.txt` come from the [PHaVE alphabetical index](https://journals.sagepub.com/doi/suppl/10.1177/1362168814559798/suppl_file/appendix_1-_alphabetical_index_-_submitted_april_17_2014.pdf). Additional learning expressions were selected with the [Oxford Phrase List](https://www.oxfordlearnersdictionaries.com/about/wordlists/oxford-phrase-list) and [English Vocabulary Profile](https://englishprofile.org/?menu=evp-online); usage was checked against [Cambridge Grammar](https://dictionary.cambridge.org/grammar/british-grammar/phrasal-verbs-and-multi-word-verbs). The definitions, examples, descriptions, and vector drawings in this repository are original. The gallery does not claim a precise frequency ranking.
